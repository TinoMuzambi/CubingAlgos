# Cubing Algos

[![Netlify Status](https://api.netlify.com/api/v1/badges/d78816a7-6f6c-466c-978a-94d0624d5af2/deploy-status)](https://app.netlify.com/sites/cubingalgos/deploys)

A lightweight reference for 2-look OLL and PLL algorithms. Each algorithm has
an interactive learning status and the page tracks overall progress locally in
the browser, without an account or remote database.

[Use the live application](https://cubingalgos.netlify.app/)

## Images

Screenshots are taken from the
[J Perm 2-look OLL and PLL playlist](https://www.youtube.com/playlist?list=PLI24ciRbl8BUHEeOBaLXY4GpaVXSULYp4).

## Privacy

Progress is stored only in the browser's `localStorage`. Clearing site data
resets the statuses to their checked-in defaults.
